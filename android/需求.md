# Android 需求摘要

## 用户角色

- 普通用户：浏览、登录注册、购物下单、评论点赞、管理自己的资料和订单。
- 管理员：使用共用账号登录轻量管理端，管理用户、商品、猫咪、评论和订单；不修改自己的个人信息。

## 顾客端需求

- 浏览首页推荐、商品列表、猫咪列表。
- 查看商品详情和猫咪详情。
- 商品、猫咪、评论点赞与取消点赞。
- 发表评论，查看和删除自己的评论。
- 加入购物车、调整数量、提交订单。
- 查看订单、筛选订单、编辑待处理订单联系信息、删除终态订单。
- 修改个人资料、头像、密码；注销普通账号。

## 管理端需求

- 管理员登录入口独立于普通登录。
- 服务页在管理员模式下显示管理工作台。
- 用户管理：查询、筛选、编辑、删除。
- 商品管理：查询、筛选、新增、编辑、上下架、删除、上传商品图片。
- 猫咪管理：查询、筛选、新增、编辑、切换状态、删除、上传猫咪照片。
- 评论管理：查询、筛选、审核、删除。
- 订单管理：查询、筛选、编辑状态和联系信息、删除；整批订单按 `items[*].orderId` 遍历处理。

## 技术要求

- Android 使用 Java、Retrofit、OkHttp、Glide、RecyclerView。
- API 地址和图片地址集中在 `app/build.gradle` 的 `BuildConfig`。
- 图片统一走相对路径和 `AppConfig.buildImageUrl`。
- 金额使用 `BigDecimal` 或字符串展示。
- 权限以后端 token 为准，不在客户端伪造授权。
