# 需求分析
账号	用户注册时登记的用户名（手机）及密码 
用户分类	用户、管理员
账户信息管理	用户与管理员都可通过该模块对自己的信息进行增加、查询、修改、删除操作，分别对应注册、登录、修改用户信息及找回密码、注销，管理员拥有对所有用户的信息进行各项操作的权限
商品查询	用户和管理员均可通过该模块浏览当前已有的服务、餐饮和猫咪用品信息
商品下单	用户查询商品信息时选择需要的商品及其数量后购买并发起订单
查看订单	用户可查看自己下单和取消的订单，并通过商品名称查询特定订单
删除订单	管理员删除所有订单状态，用户删除自己订单
修改订单	管理员修改所有订单状态，用户修改自己订单
商品点赞	用户可以点赞自己喜欢的商品
商品点赞取消	用户可以取消已点赞的商品
猫咪点赞	用户查询猫咪信息时可以给喜欢的猫咪点赞
猫咪点赞取消	用户可以取消已点赞的猫咪
发表评论	用户可以在单个猫咪的信息下发表评论
查看评论	用户查看其他人或自己发布过的评论
审核评论	管理员审核用户发表的评论，可以选择通过或退回
删除评论	发布该评论的用户或管理员可以删除评论
商品上架	管理员可以增加新上架的商品
商品下架	管理员可以删除已下架的商品
修改商品信息	管理员可以修改在售的商品信息
猫咪信息管理	管理员可通过该模块对猫咪的信息进行增加、查询、修改、删除操作
# 技术指标：
1.	实现猫咖点单平台区分用户，管理员的两端注册登录功能。
2.	实现热门猫的推荐、店内所有猫的信息展示，猫及其用品的下单与付款功能。
3.	实现猫咖服务结束后的评价，售后服务功能。
