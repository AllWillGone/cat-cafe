# Android 当前维护边界

本文档只记录 Android 端当前管理能力边界。历史规划已落地或废弃，不再保留流水式待办。

## 当前结论

- 不新建独立管理员 App，继续使用 `com.catcafe.app`。
- App 同时包含顾客端和轻量 Android 管理端。
- 管理员通过首页管理员入口登录，登录成功后服务页切换为管理工作台。
- 管理员账号是共用账号，不允许在 Android 端修改个人信息。
- 不新增数据库结构；新增能力必须先核对后端真实接口。

## 顾客端范围

- 首页、服务页、商品详情、猫咪详情。
- 登录、注册、忘记密码、修改资料、修改密码、注销账号。
- 购物车、下单、我的订单。
- 商品/猫咪/评论点赞。
- 商品/猫咪评论、我的评论。
- 我的点赞。

## 管理端范围

- 用户管理：列表、搜索、筛选、编辑、删除。
- 商品管理：列表、搜索、筛选、新增、编辑、上架、下架、删除；新增/编辑支持本地图片上传。
- 猫咪管理：列表、搜索、筛选、新增、编辑、切换状态、删除；新增/编辑支持本地图片上传。
- 评论管理：列表、搜索、审核通过、审核拒绝、删除。
- 订单管理：列表、搜索、筛选、查看、编辑、删除。

## 明确不做

- Android 端复杂统计报表。
- 管理员点赞管理。
- 管理员新增账号、修改用户类型、重置任意用户密码。
- 新增后端批次订单接口；Android 继续遍历 `BatchOrderResponse.items[*].orderId` 操作整批订单。
- 真实支付。
- 未经确认的售后/退款/客服新表和新接口。

## 约束

- 权限以后端 token 和 `/api/admin/...` 接口校验为准，Android 只做入口分流和 UI 控制。
- Android 不信任客户端传入的 `userId` 或 `userType` 执行业务授权。
- 金额使用 `BigDecimal` 或字符串展示，不使用 `float/double`。
- 商品删除尊重后端历史订单保护；有历史订单时后端可能改为下架保留。
- 评论和点赞目标是软引用，涉及目标变更时必须保留目标存在性校验。
