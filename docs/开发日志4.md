## 一、后端改动（2 处）

### 1. 生日下限校验 — `schemas.py`

`_check_birthday` 原只拦截未来日期，新增下限 1920-01-01：

```python
if v < date(1920, 1, 1):
    raise ValueError("生日日期不合理")
```

影响范围：UserUpdate、AdminUserUpdate、CatCreate、CatUpdate 全部自动生效。

### 2. 评论按点赞数排序 — `routers/comment.py`

`list_comments` 新增 `sortBy` 参数（`"default"` / `"likeCount"`），参照 `product.py` 和 `cat.py` 的既有模式：

- 新增加 `like_sub` 子查询（JOIN likes 表，likeType=1）
- `sortBy=likeCount` 时按 `COALESCE(likeCount, 0) DESC, publishTime DESC` 排序
- 默认保持 `publishTime DESC`

## 三、图片显示修复

### 问题

猫咪列表按点赞排序后部分图片消失。原因：

1. `imageUrl` 为空字符串时 `<img src="">` 不触发 `@error`，浏览器尝试加载页面 URL 作为图片，备用 emoji 无法显示
2. 原有 `@error` 用 `e.target.remove()` 手动操作 DOM，破坏 Vue 虚拟 DOM 同步，排序重渲染后图片丢失

### 修复 — `UserCats.vue` + `UserProducts.vue`

- 用 `reactive({})` 对象替代 DOM 操作：`imgError[row.catId] = true`
- 模板用响应式 `v-if` 控制显隐：`v-if="row.photoUrl && !imgError[row.catId]"`
- 添加 `:key="row.catId"` 确保排序后 Vue 正确追踪每个元素
- emoji 始终渲染为兜底，图片用绝对定位覆盖在上面
- 猫咪列宽 90 → 100，图片区域 70×70；商品列宽 80 → 90，操作列宽 170 → 200
