# Android 接手备忘

本文件是 Android 端当前事实的接手文档，不再记录逐日流水。接口、字段和数据库结构仍以 `backend/schemas.py`、`backend/routers/`、`backend/models.py` 和 `database/init.sql` 为准；发现文档和代码不一致时，先以真实代码为准。

## 当前定位

- 包名：`com.catcafe.app`
- 主线：猫咖顾客端闭环，兼有轻量 Android 管理端。
- 猫咪本体只用于展示、评论和点赞；可购买对象是猫咖服务券、餐饮和猫咖用品。
- 金额字段在 Android 使用 `BigDecimal` 或字符串展示，不使用 `float/double`。
- 认证和权限以后端 token 为准，Android 不伪造 `userId` 或 `userType`。
- 管理员账号按共用账号处理，Android 端不允许管理员修改个人信息。

## 本地运行

Debug 地址在 `android/app/build.gradle` 的 `BuildConfig` 中配置。模拟器本地后端调试建议使用：

```text
API_BASE_URL=http://127.0.0.1:8000/
IMAGE_BASE_URL=http://127.0.0.1:8000
```

模拟器访问电脑本机后端需要端口转发：

```cmd
cd G:\cat-cafe\android
.\gradlew.bat installDebug
```

`installDebug` 会触发项目里的 `adbReverseBackendPort` 任务。也可以手动执行：

```cmd
"D:\Users\yang\AppData\Local\Android\Sdk\platform-tools\adb.exe" reverse tcp:8000 tcp:8000
"D:\Users\yang\AppData\Local\Android\Sdk\platform-tools\adb.exe" reverse --list
```

后端本地启动：

```cmd
cd G:\cat-cafe\backend
.venv\Scripts\activate
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

真机同 Wi-Fi 测试时，后端改用 `--host 0.0.0.0`，并把 Android 的 `API_BASE_URL` / `IMAGE_BASE_URL` 改为电脑局域网 IP。

## 图片规则

- 后端托管静态目录：`/cats`、`/products`、`/avatars`
- Android 统一通过 `AppConfig.buildImageUrl(path)` 拼接图片地址。
- 数据库存储相对路径，例如 `/cats/mimi.jpg`、`/products/cola.jpg`、`/avatars/admin.jpg`。
- 普通用户头像上传走 `POST /api/upload`，只允许 `type=avatar`。
- 管理员图片上传走 `POST /api/admin/upload`，商品使用 `type=product` 回填 `imageUrl`，猫咪使用 `type=cat` 回填 `photoUrl`。

## 已完成能力

- 基础结构：底部导航、Retrofit / OkHttp、Glide、RecyclerView、`SessionManager`、`ApiClient`、`NetworkHelper`。
- 首页：推荐商品、热门猫咪、登录入口、管理员入口、购物车入口。
- 服务页：商品列表、猫咪搜索和列表；猫咪 Tab 已移除撸猫券模块。

- 商品/猫咪详情：详情展示、点赞、评论、下拉刷新。
- 评论：发表评论、评论点赞、我的评论、评论删除。

- 购物车和订单：加购、数量调整、下单前刷新商品状态和库存、订单列表、状态筛选、搜索、详情、编辑联系信息、终态订单删除。
- Android 管理端：用户、商品、猫咪、评论、订单管理；商品和猫咪新增/编辑弹窗支持本地选图上传。

## 管理端边界

- 管理员登录成功后仍使用同一个 Android App。
- 管理员服务页显示工作台入口：用户、商品、猫咪、评论、订单。
- 管理员不参与顾客侧购物车、点赞、评论等操作，入口隐藏或提示拦截。
- 管理员订单操作按 `BatchOrderResponse.items[*].orderId` 遍历，避免只处理同一 `batchNo` 批次第一条。
- Android 管理端只覆盖当前明确需要的轻量能力；复杂后台仍优先以 Web 管理端为主。

## 常见排查

- App 一直转圈或登录超时：先检查后端、MySQL、`adb reverse --list`。
- 图片不显示：电脑浏览器确认 `http://127.0.0.1:8000/cats`、`/products`、`/avatars` 可访问。
- Android Studio 找不到 Activity：确认 Run Configuration 包名是 `com.catcafe.app`。
- 管理员误走普通登录：普通登录页会拒绝管理员账号，提示使用管理员入口。
