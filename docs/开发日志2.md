## 二、CORS 修复

### 问题

`curl` 能调通后端 API，浏览器前端（localhost:5173 → localhost:8000）跨域被拦截，登录/注册一直失败。

### 修复

**`backend/main.py`** 添加 CORSMiddleware：

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

## 三、登录页修复（login.vue）

### 问题汇总

| 问题 | 现象 | 修复 |
|------|------|------|
| 表单标签"手机号"，但传给 API 的是 `userName` | 用户用手机号登录，但数据库存的是用户名，永远对不上 | 改为"用户名"输入框 |
| SMS 验证码登录调用 `/api/sms-login` | 后端没这个接口，永远失败 | 砍掉整个验证码登录 Tab |
| "快速体验"管理员登录直接写 localStorage | 没调 API，没有真实 JWT token，后续请求全 401 | 改为调 `/api/login` 走真实认证 |
| 登录成功没存 `token` 到 localStorage | API 拦截器读不到 token，后续请求不带 Bearer 头 | 补上 `localStorage.setItem('token', ...)` |

### 最终结构

- 用户名 + 密码表单
- "快速体验"按钮：真实调 `POST /api/login {"userName":"admin","userPassword":"123456"}`
- 登录成功存储 token / userId / userName / userType 到 localStorage
- 管理员跳 `/admin`，普通用户跳 `/cats`

## 十八、启动环境注意

### Python venv 冲突

Shell 默认 python 可能指向其他项目（如 `flask学生信息管理系统`）的 Python 3.9 venv，不支持 `str | None` 类型语法，导致 uvicorn reloader 子进程启动失败。

**正确启动方式（使用绝对路径）：**

```bash
# 后端
/d/cat-cafe/backend/.venv/Scripts/python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 8000

# 前端（必须在 web/cat-cafe-ui 目录下执行）
cd /d/cat-cafe/web/cat-cafe-ui && npx vite --host 0.0.0.0 --port 5173
```

> 注意：`npx vite` 必须在 `web/cat-cafe-ui/` 目录下执行，否则找不到 `index.html` 导致所有路由 404。
